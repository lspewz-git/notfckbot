# NotFckBot — Телеграм-бот для отслеживания сериалов и фильмов

Бот позволяет подписываться на сериалы и получать уведомления о выходе новых серий, а также вести список ожидания фильмов и узнавать о цифровом релизе. Данные берутся через [TMDB API](https://www.themoviedb.org/).

## Основные функции

- 🔍 **Поиск**: сериалы и фильмы по названию.
- 📺 **Подписки на сериалы**: три режима уведомлений — каждая серия, весь сезон, первая серия сезона + сезон целиком.
- 🎞 **Список ожидания фильмов**: бот следит за датой цифрового релиза и пишет, когда фильм становится доступен.
- 🎲 **Случайный фильм**: подбор фильма наугад.
- ⚡️ **Уведомления**: проверка обновлений каждые 3 часа (cron).
- 👥 **Поддержка групп**: работает и в личных чатах, и в группах.
- 🖥 **Веб-админка**: статистика, здоровье системы, управление чатами / подписками / списком ожидания, рассылки, просмотр логов.

## Технологии

- Node.js + Telegraf (Telegram Bot API)
- Sequelize ORM + MariaDB
- Express (админ-панель)
- Docker + Docker Compose
- Axios + socks-proxy-agent / https-proxy-agent (доступ к TMDB через прокси)
- node-cron (планировщик)

## Как запустить

### 1. Подготовка

Создайте файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
TMDB_API_KEY=ваш_ключ_от_themoviedb.org

DB_HOST=db
DB_NAME=series_bot
DB_USER=bot_user
DB_PASSWORD=bot_password
MARIADB_ROOT_PASSWORD=root_password


# Необязательно: прокси для TMDB (socks5:// или http://)
TMDB_PROXY_URL=
```

### 2. Запуск через Docker (рекомендуется)

```bash
docker compose up -d --build
```

Поднимутся MariaDB и приложение. База сохраняется в volume `mariadb_data`.

Готовые скрипты: `start.sh` / `start.bat`, `stop.sh` / `stop.bat`, `logs.bat`.

Логи:

```bash
docker compose logs -f app
```

### 3. Запуск локально (для разработки)

1. Установите зависимости:
    ```bash
    npm install
    ```
2. Запустите MariaDB и проверьте настройки в `.env` (для локального запуска `DB_HOST=db` автоматически подменяется на `localhost`, если не выставлен `IS_DOCKER`).
3. Запустите приложение:
    ```bash
    npm start
    ```

## Команды бота

- `/start` — главное меню и инициализация чата.
- `/search` — поиск сериала или фильма.
- `/subs` — список подписок.
- `/random` — случайный фильм.
- `/help` — справка.
- `/cancel` — отменить текущее действие.
- `/menu_off`, `/menu_on` — скрыть или показать кнопки клавиатуры.
- `/reset` — сбросить состояние чата.

Также доступны Reply-кнопки: 🔍 Поиск, 📺 Мои подписки, 🎲 Случайный фильм, ℹ️ Помощь.

## Админ-панель

Доступна на порту, проброшенном в `docker-compose.yml` (по умолчанию `80` → внутренний `3000`):

```
http://<host>/
```

Возможности:

- статистика по чатам, подпискам и списку ожидания;
- индикаторы состояния Telegram / TMDB / прокси и метрики CPU, RAM, uptime;
- автообновление данных (по умолчанию на паузе) и ручное обновление;
- управление чатами: блокировка, личные сообщения, добавление подписок и фильмов;
- рассылка всем пользователям;
- просмотр логов приложения;
- **Danger Zone** — полная очистка базы данных с подтверждением.

## Проверка кода

Линтер, форматтер и проверка типов настроены и запускаются одной командой:

```bash
docker compose exec app npm run check
```

По отдельности: `npm run lint`, `npm run format:check`, `npm run typecheck`.
Исправить автоматически — `npm run lint:fix` и `npm run format`.

Инструменты лежат в `devDependencies`, поэтому после их добавления образ нужно
пересобрать: `docker compose up -d --build`.

Проверка типов работает через JSDoc и `checkJs` (`admin/jsconfig.json`) — сборки
нет, в браузер уходят те же файлы. Она охватывает `admin/js/`; бэкенд не включён,
так как для него нужны типы установленных пакетов.

### Браузерные тесты

Playwright прогоняет основные сценарии панели в Chromium и в WebKit с профилем
iPhone 12 mini:

```bash
npx playwright install chromium webkit
ADMIN_URL=http://<host>/ npm test
```

Тесты только читают: диалоги открываются и закрываются, ничего не создаётся,
не изменяется и не удаляется, поэтому их безопасно направлять на рабочий
экземпляр. Панель они не поднимают — она должна быть уже запущена.

## Служебные скрипты

- `cleanup-db.js` — очистка базы от мусорных записей.
- `fix-watchlist-ids.js` — починка идентификаторов в списке ожидания.
- `reset-db.js` — полный сброс базы.

## Структура проекта

- `src/index.js` — точка входа: инициализация БД, бота, cron и админки.
- `src/bot.js` — логика бота и обработка команд.
- `src/admin.js` — HTTP API и сервер админ-панели.
- `src/cron.js` — фоновая проверка обновлений.
- `src/api/tmdb.js` — клиент TMDB (с поддержкой прокси).
- `src/models/` — модели БД: `Chat`, `Series`, `Subscription`, `Watchlist`.
- `src/db.js`, `src/database.js` — инициализация Sequelize и подключение к MariaDB.
- `admin/` — фронтенд админ-панели (статика).
