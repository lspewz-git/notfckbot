# Panel fonts

Normal variable Latin and Cyrillic subsets from `@fontsource-variable/onest@5.3.1`
and `@fontsource-variable/jetbrains-mono@5.3.0`, downloaded from the npm registry.
Both use the SIL Open Font License; the original licenses are included here.
`../css/fonts.css` retains the panel's Onest 400–700 and JetBrains Mono 400–500 weights
and optional font display. No font requests leave the panel's origin.
