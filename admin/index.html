        Proxy

        Covers everything the bot sends out — TMDB and the Telegram Bot API. Applied immediately, no restart. The database connection stays direct, inside the docker network.

        DNS: HTTP(S) and SOCKS5h resolve hostnames on the proxy side. Plain SOCKS5 resolves them on this host first — pick SOCKS5h if the local resolver is the problem.

        Not covered: image downloads by Telegram's servers and build-time traffic (npm, apt) — those never leave this container.
